WorkDays Outlook Agent

Background sync between WorkDays and Microsoft Outlook Calendar. It creates free all-day appointments for your WorkDays classifications and lets you edit or create those classifications directly from Outlook.

How it works

The agent runs in the Windows tray and syncs every few minutes. Outlook receives one free all-day calendar item per synced day.

The Outlook appointment is shown as Free, so it does not block your availability.

Outlook appointment format

FieldUsed for
SubjectDay classification, for example WorkDays - On Site or WorkDays - Remote. If the day has a marker, the subject can show [Marker].
BodyThe marker/note text for that day.
CategoryThe day type category. Days with markers can also receive a separate WorkDays - Marker category.
Show asFree time.
DurationAll-day appointment.

Marker alert in Outlook

When a synced day has a marker, the agent can make it easier to notice in Outlook:

  • Adds [Marker] to the appointment subject.
  • Adds a separate WorkDays - Marker Outlook category.
  • Enables an Outlook reminder for that item.

The default reminder is 540 minutes before the all-day appointment starts, which normally means the afternoon before. You can change this in settings using ReminderMinutesBeforeStart.

Create or change a WorkDays entry from Outlook

Create an all-day appointment on the target date using one of these subjects:

WorkDays - On SiteWorkDays - RemoteWorkDays - TravelWorkDays - PTOWorkDays - HolidayWorkDays - Sick

Write the marker/note in the appointment body. On the next sync, the agent updates WorkDays.

Clean Outlook safety option

Use Clean Outlook WorkDays items... if you want a clean Outlook calendar view.

This removes only WorkDays calendar items from Outlook. It does not erase the WorkDays database.

To avoid accidents, the agent asks for confirmation and requires the phrase CLEAN WORKDAYS OUTLOOK. By default, the agent pauses sync after cleanup so it does not immediately recreate the Outlook items.

If you later want to republish data to Outlook, resume sync and change the relevant WorkDays entries or clear the agent state file if you intentionally want a full republish.

Default sync rules

  • On Site, Remote, Travel, PTO, Holiday, and Sick are synced.
  • Blank and Weekend are not synced by default, unless they have a marker.
  • If both Outlook and WorkDays changed the same date before the next sync, Outlook wins by default.
  • Deleting an Outlook item does not clear WorkDays by default, to avoid accidental data loss.

Troubleshooting

No appointments are created

Make sure Outlook desktop is installed and your default Outlook profile opens normally.

Appointments appear as Busy

Run Sync now. The agent resets managed WorkDays appointments to Free.

Marker reminders are too early or too late

Open settings and adjust ReminderMinutesBeforeStart. For all-day items, Outlook calculates reminders relative to midnight at the start of the day.

Changes from Outlook are not coming back

Use a supported subject, such as WorkDays - Remote, and place the marker in the body.

I cleaned Outlook and items came back

Make sure PauseAfterOutlookCleanup=1. If you resume sync and change WorkDays data, the changed items may be published again.

This agent uses the local Outlook desktop COM interface. It is designed for Windows with Microsoft Outlook installed, not Outlook Web only.
