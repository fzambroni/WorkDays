Overview

Work Days is a calendar-based desktop tool used to classify each day of the year as on-site, remote, PTO, travel, sick, holiday, weekend, or blank.

The application gives you a full-year view, a monthly calendar, quarterly summaries, a yearly chart, notes for specific dates, visual highlights, import tools, backup/restore, reports, and an optional Outlook Agent for calendar synchronization.

Most common workflow: select a date, choose the day type, optionally add a marker/note, then use the quarterly and yearly panels to review your totals.

Quick start

  1. Select a date. Use the monthly calendar or click a valid day in the yearly grid.
  2. Apply a status. Use the action buttons or open the day menu from the yearly grid.
  3. Add context when needed. Use Add/Edit Marker to save a note for that date.
  4. Review the result. Check the quarter tabs and yearly summary to see how the day affects your totals.
  5. Generate a report. Use the Report menu when you need a shareable summary.

Main screen

Monthly calendar

Use it to move between months and select the active date. The Today button returns you to the current date.

Yearly grid

Shows the entire year in one place: months as rows and days as columns. Invalid days, such as February 30 or April 31, are visually disabled.

Action buttons

Use the colored buttons to assign the selected day as On Site, Remote, PTO, Travel, Sick, Holiday, or Blank.

Context menu

Click a valid day cell in the yearly grid with the secondary mouse button to open quick actions for that exact date.

Quarter tabs

Q1 to Q4 summarize each quarter, including workdays, estimated on-site target, real on-site count, remaining balance, and totals by category.

Year summary

Shows totals for the full year. Category buttons can filter the chart, and Reset restores the complete chart view.

Tip: the yearly grid is usually the fastest way to work. Select a date visually, open the context menu, choose the status, and move on.

Markers, notes, and highlights

Add/Edit Marker

Use Add/Edit Marker from the yearly grid context menu when a date needs a note, reminder, or explanation.

Markers support multiple lines. When a marker exists, the date is visually indicated in the calendar/grid, and the saved text appears in the day information/tooltip.

Highlight date

Use Highlight date from the context menu when you want a date to stand out visually without changing the actual day type.

If a blank date is highlighted, the grid shows an X so the highlight remains visible. Without that visible character, a font-color-only highlight would be easy to miss.

Good use cases: important meetings, customer visits, reminders, payroll milestones, planned exceptions, or any date you want to notice quickly in the yearly view.

Quarterly and yearly statistics

The quarterly panels show how each category contributes to the selected year. The yearly summary gives the consolidated picture.

Total days Work days Estimated on-site Real on-site Remaining Category totals

When viewing the current year, the application highlights the current quarter and shows progress to date for the current period.

Click a category in the yearly summary to focus the chart and yearly grid on that category. Click Reset to restore the full view.

Importing special days

Use Settings > Import Special Days to import multiple day entries from a text file.

The import is not limited to holidays. It can load any supported day type, including On Site, Remote, PTO, Travel, Holiday, Sick, and Weekend entries.

Careful: imported lines overwrite existing values for the same dates. Create a backup first when importing a large file.

Each line should follow this structure:

YYYY/MM/DD-TYPE-NOTE

Examples:

2026/01/01-H-New Year
2026/02/16-R-Remote planning day
2026/03/04-T-Travel to customer site
2026/07/04-H-Independence Day
2026/10/10-W-Weekend note

Accepted type codes are O, R, B, T, P, H, S, and W.

W is accepted only when the date is actually a Saturday or Sunday. Invalid lines are skipped and listed in the import result message.

Options and customization

Open Settings > Options to adjust the visual behavior of the application.

Colors

Customize colors for On Site, Remote, Holiday, PTO, Travel, Sick, Blank, Weekend, Today, Selected, Highlight, Invalid date, Graphic line, and Quarter line.

Text contrast

Use the White Font option when a category color is dark and needs better readability.

Layout

Adjust quarter border size, grid font size, cell size, and reset the application window position if it opens in the wrong place.

Click Close in the Options window to save your changes.

Outlook Agent

The Outlook Agent is an optional background companion for Work Days. It keeps your Work Days classifications visible in Microsoft Outlook Calendar without forcing you to open the main Work Days screen every time you need to review or adjust a day.

Key idea: Work Days remains the main application. Outlook becomes a convenient calendar view and editing surface for your day classifications and markers.

What appears in Outlook

The agent creates one all-day Outlook appointment for each synced Work Days entry. These appointments are created as Free time, so they do not block your availability.

Outlook fieldWhat you will see
SubjectThe day classification, such as WorkDays - On Site, WorkDays - Remote, or WorkDays - PTO. Days with a marker can also show a marker indicator in the subject.
BodyThe marker/note saved for that day.
CategoryThe matching Work Days category. Marker days can also receive a separate marker category.
Show asFree time.
DurationAll-day appointment.

Install and control the agent

Open Settings > Outlook Agent in Work Days. From there, you can install, update, start, stop, uninstall, review the agent log, and control all agent settings. The settings window now uses a single Save button; clicking it saves the settings and closes the window.

Install / Update

Installs the embedded Outlook Agent for the current Windows user. Use this again after a Work Days update to refresh the agent version.

Start / Stop

Starts or stops background synchronization. Stopping the agent does not delete Work Days data or Outlook items.

Open log

Opens the sync log when you need to check what the agent did during recent sync cycles.

Uninstall

Removes the installed agent executable from the Windows profile. Your Work Days data and saved agent settings remain available.

Save

Saves the Outlook Agent settings from Work Days and closes the settings window. If the agent is running, it will pick up the new settings on the next sync cycle.

Start with Windows

Lets the agent start automatically when you sign in to Windows, so synchronization continues without manually opening it.

Main-screen Sync

The Sync button beside the day classification buttons requests an immediate Outlook Agent sync. Use it after changing a day in Work Days when you want the Outlook calendar updated right away.

Sync behavior

The sync behavior section controls how often the agent runs and how much calendar history/future it should manage.

SettingHow to use it
Sync everyControls the background sync interval in minutes.
RangeControls how many past and future days are included in synchronization.
Outlook wins when both sides changed before syncUseful when you want Outlook edits to be treated as intentional updates.
Deleting the Outlook item clears WorkDaysUse carefully. When enabled, deleting a synced Outlook item can clear the Work Days entry for that date.
Sync Blank days / Sync Weekend daysPublishes blank or weekend entries to Outlook. Most users can leave these off to keep Outlook cleaner.
Sync Blank/Weekend only when they have markerGood middle ground: blank/weekend dates stay hidden unless they contain a useful note.
Only read items created by the agentLeave this off if you want to create Work Days items manually in Outlook. When enabled, the agent ignores appointments that were not originally created by Work Days.
Verbose logTurns on detailed troubleshooting messages. Use this when Outlook items are not syncing back to Work Days and you need to see exactly what the agent accepted, ignored, or wrote.

Immediate sync from the main screen

Use the Sync button beside the day buttons to force synchronization without opening the Outlook Agent settings window. When the agent is already running, Work Days sends a background sync request and the agent executes it immediately. If the agent is not running, Work Days can start a one-time sync using the installed agent.

When the Outlook Agent changes the Work Days database from an Outlook edit, Work Days shows an OUTLOOK CHANGE refresh message in the same area normally used for update notifications. Click it to refresh the screen and reload the latest database values.

Create or update a day from Outlook

You can create or change a Work Days entry directly from Outlook by creating an all-day appointment on the target date with one of the supported subjects. The appointment should be shown as Free time.

WorkDays - On Site WorkDays - Remote WorkDays - Travel WorkDays - PTO WorkDays - Holiday WorkDays - Sick

Short formats are also supported for quick manual entries:

W - On Site W - Remote W: Travel WD - PTO WorkDay - Sick [WD:O] [WD:R]

Put the marker/note in the Outlook appointment body. On the next sync, the agent updates Work Days.

Important: to import appointments created manually in Outlook, leave Only read items created by the agent unchecked in Settings > Outlook Agent. Also make sure the appointment date is inside the configured sync range.

Verbose log

Verbose logging is a troubleshooting option controlled from Settings > Outlook Agent. It follows the same idea as [Logging] / VerboseMode=1, but it is controlled by Work Days instead of manually editing a settings file.

When enabled, the agent records more detail about each sync cycle, including the Outlook filter used, all-day items found, subjects and categories read, dates mapped, detected Work Days status, marker text handling, and why an item was ignored.

Log location: the log file is always stored in the same folder as the installed agent executable, usually as Workdays_Outlook_Agent.log. Use Open log from Settings > Outlook Agent to review it.

Marker alerts in Outlook

Marker alerts help you notice days that have extra notes to read. In Settings > Outlook Agent, you can choose whether Work Days should:

  • add a marker indicator to the Outlook subject, such as [Marker];
  • apply a separate Outlook category for marker days;
  • show an Outlook reminder when a marker exists.

The reminder is calculated from the start of the all-day appointment. For all-day calendar items, Outlook treats the start as midnight, so a reminder set many minutes before the event may appear on the previous day.

Clean Outlook WorkDays items

Use Clean Outlook WorkDays items... when you want to remove Work Days items from Outlook and return to a clean calendar view.

This does not erase the Work Days database. It removes Work Days calendar items from Outlook only.

For safety, cleanup requires confirmation and can leave the agent stopped afterward, preventing the same Outlook items from being recreated immediately.

Good defaults for most users

  • Sync On Site, Remote, Travel, PTO, Holiday, and Sick.
  • Leave Blank and Weekend hidden unless they have a marker.
  • Keep Outlook items as Free time.
  • Use marker subject/category/reminder alerts if you rely on notes.
  • Keep cleanup enabled, but use it only when you intentionally want to reset the Outlook view.

Troubleshooting

SituationWhat to try
The context menu does not appear.Click a valid day cell in the yearly grid. Month labels and invalid dates do not open the day menu.
A day like February 30 or April 31 cannot be selected.This is expected. Those cells are invalid calendar dates and are intentionally disabled.
A highlighted blank date shows an X.This is expected. The X makes the highlight visible even when the day has no status letter.
The note for today is not visible after opening the app.Click Reload Data. If the note still does not appear, confirm the marker was saved for today’s date.
Import changed existing days.This is expected when imported lines use dates that already exist. Import overwrites those specific dates.
Restore changed more than expected.Restore replaces the current dataset with the selected backup. Create a backup before restoring if you need a safety copy.
Report does not open.Check whether the application folder is writable and whether your default browser/report viewer is available.
The window opens off-screen.Go to Settings > Options, select Reset Screen Position, then close the Options window.
The yearly view looks too tight or too large.Use Settings > Options and adjust Font size or Cell size.
Outlook Agent does not create appointments.Confirm Microsoft Outlook Desktop is installed and opens normally, then go to Settings > Outlook Agent, click Install / Update, then Start. Use Open log if it still does not sync.
Outlook appointments appear as Busy.Run the agent again or click Start. Managed Work Days appointments should be reset to Free time.
Outlook changes are not coming back to Work Days.Use a supported all-day subject such as WorkDays - Remote or W - On Site. Make sure the appointment is all-day, the date is inside the sync range, and Only read items created by the agent is unchecked. Put notes in the body, then wait for the next sync or click the main-screen Sync button.
A manual Outlook appointment is ignored.Turn on Verbose log, click the main-screen Sync button, then open Workdays_Outlook_Agent.log. The log shows whether the item was outside the date range, not all-day, filtered out, or not recognized as a Work Days subject/category.
The Work Days screen did not update after an Outlook edit.Look for the blue OUTLOOK CHANGE refresh message near the selected-date controls. Click it to reload the Work Days screen with the database changes written by the Outlook Agent.
Marker reminders are too early or too late.Open Settings > Outlook Agent and adjust Reminder minutes before all-day event. Remember that all-day Outlook items start at midnight.
Cleaned Outlook items came back.Make sure Keep agent stopped after cleanup is enabled. If the agent is started again, active Work Days entries may be republished to Outlook.
Simple recovery path: create a backup, use Reload Data, restart the application, and only then try import/restore again. That sequence avoids most accidental data loss during troubleshooting.
